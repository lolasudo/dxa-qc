# Руководство пользователя

Руководство предназначено для рентгенолаборанта, врача и специалиста по контролю качества.
Интерфейс открывается в браузере по адресу, который сообщил администратор (по умолчанию
`http://<сервер>:7077`). Устанавливать ничего не нужно, интерфейс работает без интернета.

> Результат сервиса вспомогательный. Решение о повторном исследовании принимает специалист.

## Главная страница

- **Шапка:** название сервиса, статус (зелёный «Сервис работает» - модели готовы; «Загрузка
  моделей...» - сервис стартует, до 1-2 минут; красный - модели не загружены, обратитесь к
  администратору) и переключатель светлой и тёмной темы. По умолчанию берётся тема системы, выбор
  запоминается.
- **Синий баннер** кратко объясняет, что проверяет сервис.
- **Две плашки под баннером** - разделы: «Пакетная проверка» (архив исследований) и «Один снимок».
  Выбранная плашка обведена синим. Переключаться можно мышью или стрелками на клавиатуре; раздел
  «Один снимок» открывается прямой ссылкой `.../#study`.
- Если администратор включил вход по паролю, браузер при первом открытии спросит логин и пароль.

## Пакетная проверка

1. Перетащите в область загрузки ZIP-архив с исследованиями или отдельный DICOM-файл. Внутри
   архива допускаются любые вложенные папки. Имена файлов не важны: область определяется по
   изображению.
2. Карточка задачи покажет ход обработки: «В очереди» -> «Анализ снимков» -> «Готово», с числом
   обработанных снимков. Страницу можно не держать открытой: задача выполняется на сервере и
   хранится 24 часа.
3. **Сводка:** всего снимков, качественные, с нарушениями, не обработаны.
4. **Таблица результатов:** файл, область, вероятность нарушения, нарушения, время. Доступны
   сортировка, фильтры по области, вердикту и нарушению и поиск по имени файла или
   StudyInstanceUID.
5. **Скачать отчёт** - ZIP для архива или передачи:

   | Файл | Что внутри |
   |---|---|
   | `results.xlsx`, `results.csv` | итоговая таблица: одна строка на снимок |
   | `results_details.csv` | проекция, заключение, вероятность по каждому критерию, измерения, предложения по коррекции |
   | `results_errors.csv` | причины для необработанных файлов (если такие есть) |
   | `results_reviewed.csv` | решения специалиста рядом с решениями модели (если решения были) |
   | `visualization/*_preview.png`, `*_overlay.png` | снимок и слой разметки нарушений |
   | `dicom/*_sr.dcm`, `*_sc.dcm` | DICOM SR с заключением и DICOM-снимок с разметкой - открываются в PACS и DICOM-просмотрщиках вместе с исходным исследованием |

## Карточка снимка

Кнопка с глазом в строке таблицы (или двойной щелчок по строке) открывает карточку снимка
в боковой панели.

- **Изображение** показано в правильных физических пропорциях. Переключатель «Показать разметку
  нарушений» накладывает слой: ось позвоночника или бедра, найденные посторонние предметы,
  границы поля, металл (эндопротез). Легенда поясняет цвета.
- **Вердикт:** «качественное» или «есть нарушение» с вероятностью нарушения, область и проекция
  (для бедра - сторона).
- **Заключение** - текст на русском: какие критерии нарушены и на чём основан вывод.
  Пример: «Наклон оси позвоночника: 7.3° (допустимо до 5°).»
- **Вероятность по каждому критерию** и **измерения:** наклон оси позвоночника или бедра, высота
  и ширина поля, металл.
- **Предлагаемая коррекция:** что изменить в укладке или поле сканирования, например «Выровнять
  пациента по средней линии стола: наклон оси 6,9° уменьшить до 5° и менее». Число приводится,
  только когда его можно надёжно измерить по снимку.
- **Решение специалиста:** «Подтвердить результат» или «Исправить» - выбрать итог
  (качественное / есть нарушение), отметить нарушения, оставить комментарий. Решение попадает в
  `results_reviewed.csv`, а DICOM SR перевыпускается как проверенный (VERIFIED). Решение можно
  изменить. В таблице у проверенных строк появляется отметка «подтверждено / исправлено
  специалистом».
- **DICOM SR** и **DICOM с разметкой** - кнопки скачивания DICOM-объектов этого снимка.
- **Идентификаторы DICOM:** StudyInstanceUID, SOPInstanceUID.

### Как читать вероятность

`quality_prob` - откалиброванная вероятность того, что эксперт признал бы исследование
некачественным. Вердикт «есть нарушение» выставляется, если сработал хотя бы один критерий или
общая оценка выше порога. Поэтому вердикт может быть «нарушение» и при вероятности около 0.5.
Порог выбран по F1 на кросс-валидации.

Надёжнее всего определяются посторонние предметы и наклон оси позвоночника. Укладка бедра - самый
трудный критерий: эксперты сами не всегда в нём согласны (см.
[ограничения](../backend/README.md#ограничивающие-факторы)).

## Один снимок

Раздел для быстрой проверки одного DICOM-файла сразу после исследования, пока пациент ещё рядом.
Загрузите файл, и через секунду появится та же карточка с вердиктом, заключением и разметкой.

## Если что-то пошло не так

| Сообщение | Что это значит |
|---|---|
| «Обработка не выполнена» у строки | файл не является пригодным DICOM или область не распознана; причина - в строке и в `results_errors.csv` |
| «Файл слишком большой» | архив больше 2 ГБ: разделите его на части |
| «Очередь заполнена, повторите позже» | сервер обрабатывает другие пакеты; повторите через несколько минут |
| «Задача не найдена или удалена по сроку хранения» | прошло больше 24 часов: загрузите архив заново |
| Статус сервиса красный | модели не загружены: сообщите администратору |
