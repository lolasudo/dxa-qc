# DXA QC - frontend

Веб-интерфейс DXA QC: React 18, Ant Design 5, React Query, сборка Vite. В production-образе
статику отдаёт nginx, он же проксирует `/api` на backend и выставляет заголовки безопасности.
Запуск всего решения описан в [корневом README](../README.md).

## Разработка

```bash
npm ci
npm run dev        # http://localhost:5173, /api проксируется на 127.0.0.1:8000
npm test           # vitest, Testing Library
npm run lint
npm run typecheck
npm run build      # проверка типов и сборка в dist/
```

Для полноценной работы нужен запущенный backend; удобнее всего поднять оба процесса командой
`npm run dev` из корня репозитория.

## Функциональность

- пакетная проверка: загрузка ZIP или DICOM, прогресс обработки, сводка, таблица с фильтрами и
  поиском, выгрузка архива результатов;
- проверка одного снимка;
- карточка снимка: изображение с переключаемым слоем разметки, вердикт, область и проекция,
  заключение, вероятности по критериям, измерения;
- предложения по коррекции и решение специалиста (подтвердить или исправить с комментарием),
  скачивание DICOM SR и снимка с разметкой;
- светлая и тёмная темы.

## Структура

| Путь | Назначение |
|---|---|
| `src/api`, `src/lib/http.ts` | клиент REST API: таймауты, разбор ошибок, загрузка с прогрессом |
| `src/types/api.ts` | контракт с backend, меняется синхронно с `backend/src/dxa_qc/api` |
| `src/hooks` | запросы React Query: состояние сервиса, задачи, результаты, решение специалиста |
| `src/pages` | разделы «Пакетная проверка» и «Один снимок» |
| `src/components` | карточка снимка, панель решения специалиста, таблица, сводка, загрузка файла |
| `src/theme`, `src/styles` | палитры тем, тема antd, CSS-переменные |
| `nginx.conf`, `security-headers.conf` | прокси, лимиты запросов, CSP и прочие заголовки |

Раздел приложения хранится в адресе (`#study`), поэтому ссылку на него можно передать.

## Конфигурация

Переменные сборки (`.env.example`):

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `VITE_API_BASE_URL` | `/api/v1` | адрес API |
| `VITE_POLL_INTERVAL_MS` | `3000` | период опроса статуса задачи |
| `VITE_MAX_UPLOAD_SIZE_MB` | `2048` | лимит размера файла на клиенте; должен совпадать с backend и nginx |

## Дизайн и доступность

Шрифт Golos встроен в сборку (`@fontsource-variable/golos-text`), основной цвет `#1F6BFF`. Обе
темы строятся из одной палитры (`src/theme/palette.ts`); контраст текста - не ниже 4,5:1.
Реализованы видимый фокус, ссылка «Перейти к содержимому», роли `tablist`/`tab` у разделов и
поддержка `prefers-reduced-motion`.

## Безопасность

Интерфейс не разбирает DICOM: превью и разметку формирует backend. Внешних шрифтов, CDN и
аналитики нет; CSP запрещает загрузку ресурсов с других источников, поэтому интерфейс работает
без интернета. Пользовательские данные выводятся только как текст, без `innerHTML`.
